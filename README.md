# Sparkling Mutuals Bot

Discord companion for the Sparkling Mutuals community.

- [Privacy notice and deletion requests](PRIVACY.md)
- [SM bot commands](https://discord.com/channels/1567856303341051905/1568200051891642388)

The bot is in local testing. Four guild commands are registered in SM, and its HTTP interaction endpoint is connected through a temporary HTTPS tunnel. A real `/help` command returned the expected private guide with support and download links. Safari statistics and release announcements remain disabled during setup. Runtime source is currently prepared locally.

The stable, beta and action-release channels are prepared. Automated posting still requires the remaining storage, signing and publication integration setup.

The server owner, Discord username **ethxn15**, is the bot's operator and privacy contact. Do not send credentials in issues, Discord messages or support posts.
